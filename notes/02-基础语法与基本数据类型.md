# 02-基础语法与基本数据类型

## 一、基础语法

### （一）标识符
- 标识符由大小写字母（`A-Z`, `a-z`）、数字（`0-9`）和下划线（`_`）组成。
- 第一个字符必须是大小写字母（`A-Z`, `a-z`）或下划线（`_`）。
- 标识符对大小写敏感，例如`name`和`Name`是不同的标识符。
- 禁止使用保留关键字，例如`if`、`else`、`for`等。

#### 1.1 关键字
> 官方文档：https://docs.python.org/zh-cn/3/reference/lexical_analysis.html#keywords
```

None       break      except     in         raise
True       class      finally    is         return
and        continue   for        lambda     try
as         def        from       nonlocal   while
assert     del        global     not        with
async      elif       if         or         yield
```


## 二、基本数据类型

### （一）变量定义与赋值
和`JavaScript`不同，`Python`定义变量无需使用关键词定义变量。
```python
# 基本赋值
name = "Hlxuan."
age = 24

# 多变量赋值
a, b = 1, 2

# 链式赋值
x = y = z = 1

# 解包赋值
list = [6, 9]
i, j = list

# 交换变量
a, b = b, a
```

### （二）整数`int`和浮点数`float`
```python
# 整数int
count = 100
negative = -10

# 下划线分隔，提升代码可读性，代码编译时会自动移除
amount = 1_000_000

# 浮点数float
pi = 3.14

# 进制表示
binary = 0b1010    # 二进制
octal = 0o12       # 八进制
hexadecimal = 0xA  # 十六进制
```

### （二）字符串`str`
```python
str = "hello world"
```

### （三）布尔值`bool`
和`JavaScript`不同，布尔值首字母必须是大写。

```python
is_active = True
is_admin = False
result = 0 > 1         # 结果为Flase 
truthy = bool("text")  # 非空字符串结果为True
falsy = bool("")       # 空字符串结果为False
```

### （四）空值`None`
```python
result = None
```


## 三、字符串操作

### （一）索引与切片

#### 1. 索引
```python
s = "hello world"
s[0]               #值为h
s[-1]              #值为d
```

#### 2. 切片
```python
s = "hello world"
s[1:5]             #值为ello
s[:5]              #值为hello
s[6:]              #值为world
s[::2]             #值为hlowrd
s[::-1]            #值为dlrow olleh
```

### （二）常用字符串方法
```python
s = "  Hello, World  "
# 去掉两端空白
s.strip()
# 全大写
s.upper()
# 全小写
s.lower()
# 替换
s.replace("World", "Python")
# 按逗号分割
s.split(",")
# 用-连接列表
"-".join(["a", "b", "c", "d"])
```

### （三）字符串格式化三种方式
```python
name = "Allen"
age = 24
height = 1.80

# 方式一：使用%格式化
"I'm %s, %d years old." % (name, age)

# 方式二：使用str.format()
"I'm {}, {} years old.".format(name, age)

# 方式三：f-string
f"I'm {name}, {age} years old."
f"Next year I'll be {age + 1} years old."
f"My height is {height} cm."
```
