# 03 - 控制流

## 一、条件判断

和JavaScript不同，在Python中不需要使用括号`()`，使用缩进来表示代码块，而不是用花括号`{}`，在条件语句的末尾必须加上冒号`:`。

### （一）if语句

``` python
age = 18
if age >=18:
    print("你已成年")
```

### （二）if-else语句
``` python
age = 16
if age >= 18:
    print("你已成年")
else:
    print("你还未成年")
```

### （三）if-elif-else语句
> `elif`相当于在JavaScript中的`else if`。

```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

### （四）三元运算符
在JavaScript中，三元运算符语法是`条件 ? 结果1 : 结果2`，而Python的语法是`结果1 if 条件 else 结果2`。

```python
age = 19
status = "成年" if age >= 18 else "未成年"
print(status)
```

### （五）match-case语句（Python 3.10+新增）
Python在3.10版本中引入了`match-case`，类似于JavaScript中的`switch-case`。

```python
status_code = 404
match stauts_code:
    case 200:
        print("正常")
    case 404:
        print("资源不存在")
    case 500:
        print("服务器故障")
    case _:
       print("未知错误")
```

## 二、循环结构

### （一）while循环
```python
count = 0
while count < 5
    print(f"当前计数：{count}")
    count += 1
```

### （二）for循环
```python
for char in "Hello":
    print(char)
    
fruits = ["apple", "banner", "cherry"]
for fruit in fruits:
    print(fruit)
```

### （三）range函数
```python
for i in range(5)
   print(i)
   
for i in range(2, 5)
    print(i)
```

### （四）break和continue

#### break

用于结束整个循环，跳出循环体。

```python
for i in range(5):
  if i == 3:
     break
  print(i)
```

上方示例会输出「0, 1, 2」。


#### continue

用于结束本次循环，直接进入下一次循环。

```python
for i in range(5):
  if i == 3:
    continue
  print(i)
```

上方示例会输出「0, 1, 2, 4」


### （五）循环中的else语句
这个是Python中特有的语法，当循环正常结束没有被break中断的时候，就会自行else语句里面的代码。

```python
for i in range(5)
  print(i)
else:
  print("循环结束")
```

## 三、练习题

智能温控风扇的程序需要增加用户交互与自动控制逻辑。目前需要根据用户输入的温度和环境状态，决定风扇的工作模式。

请在[exercises/03-control-flow/fan.pyfan.py](../exercises/03-control-flow/fan.py)文件中编写代码，完成以下任务：

### 1. 温度判断
使用`input()`函数获取用户输入的温度（需转换为浮点数）。
- 如果温度>=30，打印“高温模式：风扇最大转速”。
- 如果温度在20到29之间，打印“舒适模式：风扇中速运转”。
- 如果温度在10到19之间，打印“凉爽模式：风扇低速运转”。
- 如果温度<10，打印“寒冷模式：风扇关闭”。

### 2. 倒计时启动
风扇启动前需要有3秒倒计时。使用`while`或`for`循环配合`range()`打印“3, 2, 1, 启动！”。

### 3. 传感器模拟
假设有5个温度传感器，温度值分别为 [28, 32, 25, 18, 35]。使用`for`循环遍历，如果检测到温度>=30，打印警告“警告：传感器X温度过高！”，并使用`continue`跳过后续处理；如果温度正常，打印“传感器X正常”。如果所有传感器都正常，尝试使用`for...else`结构打印“所有传感器均正常”。
